# Security policy

Katak opens files from anywhere, so malformed input must never cause
memory corruption, code execution or writes to the wrong file.

## Supported versions

Security fixes go into the latest release.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/Erkinbek/katak/security/advisories/new)
(Security tab → "Report a vulnerability"), not in a public issue. Include
the Katak version, your OS and, if possible, a small file that reproduces
the problem. Reports are answered as soon as possible.

Crashes, hangs or a frozen window on unusual files are bugs too, but
unless they can be exploited they can go into a regular
[issue](https://github.com/Erkinbek/katak/issues).
