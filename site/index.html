Open huge CSV files instantly

Katak is a free, open-source viewer and editor for CSV and TSV files of 1 GB, 10 GB, 50 GB and more. Search, filter, sort, edit and convert them without loading the file into memory, on Windows, macOS and Linux.

CSV file too large for Excel?

Excel and LibreOffice Calc stop at 1,048,576 rows. Text editors try to read the whole file into memory and freeze. Importing into a database takes minutes before you see a single row.

Katak memory-maps the file, reads only what is on screen and builds a sparse index in a background thread, so a file with hundreds of millions of rows opens as fast as a small one and the window never freezes. Filter or select the rows you need and export them as a CSV that Excel can open, or work with the whole file directly.

Features

Opens any CSV, TSV or delimited text file

Delimiter, quotes, header, encoding and line endings are detected from the first megabyte. Change anything in the parsing dialog with a live preview: comma, semicolon, tab, pipe or custom multi-character delimiters, whitespace-aligned columns, quote and escape styles, skipped and comment lines, and a raw-text view.

Search and filter at gigabytes per second

Plain text or regex search with match case, whole word, whole cell and column scope. Per-column filters (contains, equals, starts with, regex, empty, numeric range) combined with AND. Results appear while the scan runs, and both see your unsaved edits.

Sorts millions of rows

Sort by any column as numbers, dates or text, ascending or descending. 12 million rows sort in 1.2 seconds within a configurable memory budget. The sort is a view: the file only changes if you export or save in sorted order.

Edits like a spreadsheet, saves without surprises

Edit cells, insert and delete rows and columns, copy and paste with Excel, find and replace with regex capture groups, and undo anything. Saving keeps the original delimiter, quoting, encoding and line endings, copies untouched rows byte for byte and replaces the file atomically, with an optional backup.

Converts and exports

Export all rows, the filtered or sorted rows, or a selection, with another delimiter, quoting, encoding or line ending: CSV to TSV, semicolons to commas, Windows-1251 to UTF-8. Exports stream, so a 10 GB conversion uses about 50 MB of RAM.

Awkward files welcome

Multi-line quoted fields, ragged rows, unterminated quotes, NUL bytes, invalid UTF-8, a single 500 MB cell.

Wide files

Only visible rows and columns are parsed and drawn, so 10,000 or 1,000,000 columns scroll smoothly.

Every encoding

UTF-8, UTF-16, Windows code pages, ISO-8859, KOI8, Shift_JIS, GBK, Big5 and more, auto-detected.

Network drives

Slow or disconnected shares are read in the background and never freeze the window.

Changes on disk

If another program appends to or replaces the open file, Katak offers to reload it.

Keyboard friendly

Go to row or byte offset, F3 to the next match, Ctrl+Home/End, tabs, zoom, light and dark themes.

Frequently asked questions

How do I open a CSV file that is too large for Excel?

Open it in Katak with File → Open, drag and drop, or katak file.csv. There is no row limit: the first rows appear immediately and the rest of the file is indexed in the background. To use the data in Excel, filter it or select the part you need and export it as a smaller CSV.

How large a CSV file can Katak open?

Files are memory-mapped, so the limit is your disk, not your RAM. Katak is tested with 50 GB files, 119 million rows, 100 million one-character rows and 1,000,000 columns. The index takes about 0.03% of the file size.

Does Katak load the whole file into memory?

No. Only the visible rows and columns are read and parsed. Search, filter, sort and save stream through the file on background threads with bounded memory; a 50 GB file open and indexed uses about 127 MB of RAM.

Will saving change data I did not edit?

No. Untouched rows are copied byte for byte; Katak never reformats numbers or dates, strips leading zeros or trims whitespace. Saves go to a temp file that atomically replaces the original, so a crash never leaves a half-written file.

Can Katak convert a huge CSV file to another delimiter or encoding?

Yes. Export writes all rows, the filtered rows, the sorted order or a selection with another delimiter, quoting policy, encoding or line ending. It streams, so converting a 10 GB file needs about 50 MB of RAM.

Is Katak free?

Yes. Katak is open source under the MIT license, with no account, no telemetry and no network access. The source code is on GitHub.
